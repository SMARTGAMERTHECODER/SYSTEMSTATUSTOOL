# SYSTEMSTATUSTOOL
A lightweight, 158KB native C# utility that runs a full system diagnostic scan on PC hardware, CPU, RAM, and storage health.

A fast, ultra-lean, and completely independent system diagnostic application for Windows built using C#. Unlike heavy corporate apps that take up hundreds of megabytes, this tool is fully optimized at a mere 158 KB. 

It provides instant hardware diagnostics and readings directly from your system components without any installation clutter.

## Features
- **[SYSTEM]** Reads motherboard data, BIOS version, and system service identifiers.
- **[CPU]** Scans processor models (optimized for AMD Ryzen) and monitors active core counts.
- **[RAM]** Displays total installed system memory and configuration.
- **[DRIVE]** Checks storage health and monitors S.M.A.R.T. status for solid-state drives (SSD).
- **[BATTERY]** Reports live battery charge percentage and health status.

## How to Run (Portable)
1. Download the `DIAGNOSTICS.zip` file from this repository.
2. Right-click the `.zip` file and select **Extract All**.
3. Double-click the `DIAGNOSTICS.exe` file inside to run it instantly—no installer required!

---

> ⚠️ **Note for First-Time Users:** Because this is an independent, unregistered utility, Windows SmartScreen might show an "Unknown Publisher" blue warning when you first launch it. This is completely normal for independent software. Simply click **"More Info"** and then select **"Run Anyway"** to launch the tool.
